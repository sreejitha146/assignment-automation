# Assignment Automation Project

## Overview
This repository contains a complete automation assignment demonstrating knowledge of Java and Python OOP concepts, Selenium automation, TestNG, Maven, API testing using Postman, and basic performance testing concepts using JMeter.

The project is structured clearly for easy understanding, evaluation, and GitHub submission.

## Java OOPs
This module demonstrates object-oriented programming concepts such as inheritance, method overriding, and polymorphism. A base Account class is extended by SavingsAccount and CurrentAccount classes to implement different interest calculation behaviors.

## Python OOPs
The Python module demonstrates class creation, inheritance, and constructor usage. The Student class is inherited by the School class to display student details.

## Selenium Automation using Java
Selenium WebDriver with TestNG is used to automate basic UI validation on the MakeMyTrip website. TestNG annotations manage browser setup and teardown, and XPath locators are used to identify web elements.

## TestNG Framework
TestNG is used for test execution control, annotations, and assertions. It supports structured and reusable test cases.

## Maven
Maven is used for dependency management and project configuration. Selenium and TestNG dependencies are defined in the pom.xml file.

## Selenium Automation using Python
Python Selenium tests are implemented using Pytest. Fixtures are used to manage browser initialization and cleanup, and a basic UI validation test is included.

## Postman API Testing
A Postman collection in JSON format is included to demonstrate basic REST API operations such as GET, POST, PUT, and DELETE.

## JMeter
JMeter usage is explained through a placeholder file describing thread group creation, HTTP requests, assertions, and listeners for performance testing.

## Status
The project is complete, properly structured, GitHub-safe, and ready for assignment submission.
